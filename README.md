A program that writes one short, funny rant — about a self-checkout machine that treats every shopper like a suspect — to `/output/entry.txt`, for make.fun's "Angry Judge: The Short Rant Contest" bounty, $2 in USDC.

## Run it

```sh
python3 main.py
```

Writes one rant (377 characters) to `/output/entry.txt`.

## The rant

> The self-checkout screamed UNEXPECTED ITEM IN THE BAGGING AREA at rice I had already scanned, weighed and apologised to. I stood there, hands up like a suspect, while a teenager in a vest strolled over, pressed one button and fixed in three seconds what the machine spent two minutes accusing me of. I didn't steal anything. I just wanted rice. The machine wanted a confession.
